# Thai Election 2026 — Visual Analytics

Mini Project 2 for **2603646 Information Visualization**: a visual analytics system for the results of the 2026 Thai general election.

🔗 **Live site:** https://sroisala.github.io/thai-election-2026-viz/

## Structure
```
index.html        # page
css/style.css     # styles
js/main.js        # D3 charts & interactions
data/             # processed datasets (JSON/CSV)
```

## Run locally
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
(Opening `index.html` directly won't load the JSON — use a local server.)

## Deploy
Pushing to `main` redeploys GitHub Pages automatically (Settings → Pages → Deploy from branch `main` / root).
