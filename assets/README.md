# รูปหัวหน้าพรรค นายกฯ และโลโก้พรรค

แผงด้านขวาอ่านรูปจากโฟลเดอร์นี้ตาม path ใน `data/panel/party-meta.json`

- `assets/people/` รูปหัวหน้าพรรคและนายกรัฐมนตรี (คนเดียวกันที่ปรากฏหลายปีใช้ไฟล์เดียวกัน)
- `assets/logos/` โลโก้พรรค
- `assets/manifest.csv` รายการไฟล์ทั้งหมดที่ต้องใช้ พร้อมช่องกรอกลิงก์ที่มา และสิทธิ์การใช้งาน
- `assets/CREDITS.md` ตารางที่มาของรูปและของชื่อบุคคล (ตารางรูปสร้างจาก manifest อัตโนมัติ)

## ใส่รูปเร็วที่สุด

1. เปิด `manifest.csv` กรอก `url` (ลิงก์ตรงของรูป) `source_page` (หน้าที่เอารูปมา) `license` (สิทธิ์การใช้งาน) และ `added_by`
2. รัน `python3 scripts/fetch_assets.py` บนเครื่องที่ออกอินเทอร์เน็ตได้
3. รัน `python3 scripts/fetch_assets.py check` เพื่อดูว่ายังขาดอะไร
4. commit ไฟล์รูป `manifest.csv` และ `CREDITS.md` ไปพร้อมกัน

รายละเอียดเพิ่มอยู่ในส่วน "วิธีใช้" ของ `CREDITS.md`

ถ้าไม่มีไฟล์รูป หน้าเว็บจะแสดงวงกลมสีพรรคพร้อมอักษรตัวแรกแทน จึงใช้งานได้ก่อนใส่รูปครบ

แนะนำ: รูปคน สี่เหลี่ยมจัตุรัส อย่างน้อย 160×160 px (JPG) · โลโก้ พื้นโปร่งใส อย่างน้อย 128×128 px (PNG) ใช้รูปที่มีสิทธิ์นำมาใช้ได้ และกรอกที่มาให้ครบเสมอ
