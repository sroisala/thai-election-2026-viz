# ข้อมูล

ผลเลือกตั้งปี 2562, 2566 และ 2569 ครบแล้ว ไม่ต้องเพิ่มปี และไม่ต้องแก้ไฟล์เหล่านี้

- `years/2562.json` `years/2566.json` `years/2569.json` ผลคะแนนรายเขต
- `years/index.json` รายชื่อปีที่หน้าเว็บโหลด มีแค่สามปีนี้
- `map.json` รูปจังหวัด
- `provinces.json` ชื่อจังหวัด ใช้คัดลอกชื่อไปใส่ในไฟล์ด้านล่าง
- `source/` ไฟล์ดิบของปี 2569

## งานที่เหลือ: แผงด้านขวา

ผลคะแนนมาจากไฟล์ปีอยู่แล้ว ไม่ต้องกรอกซ้ำ ไฟล์ที่ต้องเติมมีสองไฟล์ ตอนนี้ยังว่าง `{}` หน้าเว็บจะขึ้นว่ายังไม่มีข้อมูลจนกว่าจะใส่

วิธีทำ: เปิดไฟล์ตัวอย่าง แล้วก็อปเนื้อหาไปวางทับไฟล์จริง จากนั้นเปลี่ยนตัวเลขกับข้อความให้เป็นข้อมูลจริง อย่าแก้ไฟล์ที่ลงท้าย `.example.json` เพราะหน้าเว็บไม่ได้อ่านไฟล์นั้น

ชื่อพรรคต้องสะกดตรงกับในไฟล์ปีของปีนั้น ชื่อจังหวัดต้องตรงกับ `provinces.json` ทุกตัวอักษร เช่น `กรุงเทพมหานคร` ไม่ใช่ `กทม.`

### 1. `panel/policies.json`

ใช้ในแท็บ **นโยบาย** หลังคลิกเขต หน้าเว็บโชว์นโยบายของพรรคที่ชนะในปีที่เลือก และให้กรองตาม `topic` ได้

ตัวอย่างอยู่ใน `panel/policies.example.json`

```json
{
  "2569": {
    "ภูมิใจไทย": [
      { "topic": "เศรษฐกิจ", "title": "ชื่อนโยบาย", "detail": "อธิบายสั้น ๆ" }
    ]
  }
}
```

ใส่ได้ทั้งสามปี ชื่อพรรคของแต่ละปีไม่เหมือนกัน ปี 2566 ใช้ `ก้าวไกล` ปี 2569 ใช้ `ประชาชน` ปี 2562 ใช้ `อนาคตใหม่`

### 2. `panel/province-stats.json`

ใช้ในแท็บ **GPP และนักท่องเที่ยว** เป็นตัวเลขทั้งจังหวัด ไม่ใช่รายเขต

ตัวอย่างอยู่ใน `panel/province-stats.example.json`

```json
{
  "2569": {
    "เชียงใหม่": { "gpp": 250000, "gppUnit": "ล้านบาท", "tourists": 8000000, "note": "ที่มาของตัวเลข" }
  }
}
```

`gpp` ใส่เป็นล้านบาท ถ้าหน่วยอื่นให้ใส่ `gppUnit` ด้วย `tourists` คือจำนวนคน `note` เว้นได้
